# macOS — quick reference

Shortcuts and tooling for daily frontend development on Mac.

### Window & system

| Action | Shortcut |
|--------|----------|
| Spotlight search | `Cmd+Space` |
| Switch app window | `Ctrl+Left/Right` |
| Emoji/symbol picker | `Ctrl+Cmd+Space` |
| Screenshot area | `Cmd+Shift+4` |

### Terminal / Homebrew

```bash
brew services list          # check running services
brew install postgresql@16    # install package
brew uninstall postgresql@16
```
