# macOS — quick reference

Ярлыки и инструменты для ежедневной разработки интерфейсов на Mac.

### Window & system

| Действие | Ярлык |
|--------|----------|
| Поиск в центре внимания | `Cmd+Space` |
| Переключить окно приложения | `Ctrl+Left/Right` |
| Выбор эмодзи/символов | `Ctrl+Cmd+Space` |
| Область снимка экрана | `Cmd+Shift+4` |

### Terminal / Homebrew

```bash
brew services list          # check running services
brew install postgresql@16    # install package
brew uninstall postgresql@16
```
