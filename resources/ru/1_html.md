### Is HTML a programming language?

HTML — это **язык разметки**, а не тьюринг-полный язык программирования. Он описывает структуру и семантику документа; в нем нет переменных, циклов или условий.

Его часто классифицируют как **предметно-ориентированный язык (DSL)** для гипертекстовых документов.

* https://stackoverflow.com/questions/809574/what-is-a-domain-activate-language-anybody-using-it-and-in-what-way* https://gomakethings.com/is-html-a-programming-language/

### Element, tag, and attribute

| Срок | Определение |
|------|------------|
| **Тег** | Синтаксис разметки (`<p>`, `</p>`), который вводит элемент в исходный код |
| **Элемент** | Узел в дереве DOM — открывающий тег + контент + закрывающий тег (или тег void) |
| **Атрибут** | Дополнительные метаданные «ключ/значение» в элементе (`href`, `class`, `alt`) |

### Void (empty) elements

У элементов Void нет закрывающего тега и содержимого: `<img>`, `<br>`, `<input>`, `<meta>`, `<link>`, `<hr>`, `<area>`, `<base>`, `<col>`, `<embed>`, `<source>`, `<track>`, `<wbr>`.

### Content categories (HTML5)

| Категория | Цель | Примеры |
|----------|---------|----------|
| Метаданные | Информация о документе, не отображается | `head`, `title`, `meta`, `link`, `style` |
| Разделение | Схема документа | `article`, `section`, `nav`, `aside` |
| Рубрика | Названия разделов | `h1`–`h6` |
| Фразировка | Семантика встроенного текста | `span`, `a`, `em`, `strong`, `code` |
| Поток | Большая часть содержания тела | `div`, `p`, `ul`, `table`, `form` |
| Встроенный | Внешние ресурсы | `img`, `video`, `iframe`, `canvas` |
| Интерактивный | Взаимодействие с пользователем | `a`, `button`, `input`, `select`, `textarea` |

### Code formatting rules

* Один элемент в строке для удобства чтения.
* Последовательный отступ на уровне вложенности.
* Всегда используйте двойные кавычки для значений атрибутов.
* Подтвердите с помощью https://validator.w3.org/.
